## 1. 三句话版本

1. **你是死者**。你是靠吸食活人血液维持存在的捕食者，而心底那头**心兽**永远在低语。
2. **你不能被看见**。**避世戒律**是全体血族唯一的共同底线，而在现代之夜，守住它比历史上任何时候都难。
3. **你身边的人都在下棋**。**秘盟**、**叛党**、**魔宴**、独立氏族、以及人类世界的**第二审判庭**，各有各的算盘，而新生儿通常是棋盘上最先被牺牲的那一格。

这三句话构成了本编年史的全部张力来源：**对外的伪装、对同族的政治、对自己的战争**。

## 2. 核心体验：这个游戏到底在玩什么

### 2.1 个人恐怖，而非怪物打怪

V5 的核心恐怖不是"打不过的敌人"，而是**你还剩下多少自己**。每一次猎食、每一次狂乱、每一次为了活下去而说谎或杀人，都在侵蚀角色的人性。说书人的工作不是设计更强的 Boss，而是让玩家在做出选择之后，自己问出那句"我为什么会变成这样"。

### 2.2 三条同时运转的压力线

| 压力线 | 压迫来源 | 典型表现 |
| --- | --- | --- |
| **生存线** | 饥渴、阳光、猎人、庇护所被端 | 今晚吃什么？能不能活着看到明天的日落？ |
| **政治线** | 领地、恩情、血缚、地位、派系 | 我可以相信谁？我欠了谁？谁打算用我？ |
| **内在线** | 心兽、人性、信念、血锚 | 我还能不能认出镜子里（或者照片里）的那个人？ |

三者互相咬合：为了生存打破避世戒律，就会招来政治清算；为了政治安全去杀人，就会击穿人性底线。

### 2.3 基调：都市哥特朋克（Gothic-Punk）

哥特的一面是古老、华美、颓败、仪式感与永恒的权力；朋克的一面是肮脏的街头、失控的暴力、被遗忘的边缘人与不服从的年轻人。现代之夜把这两者按在同一座城市的夜景里：**极乐境**里穿着礼服啜饮红酒的长老，和三条街外在下水道里舔血的稀血，属于同一个社会。

### 2.4 游戏的最重要一句台词

> "一头兽，我便是；唯恐我化为兽。"
> （A Beast I am, lest a Beast I become.）

这不是氛围文案，而是机制和叙事的总纲：角色既是捕食者，也是自己心兽的囚徒与看守。

## 3. 血族的存在状态

### 3.1 初拥（Embrace）

**初拥**是把凡人转化为血族的过程：尊长（Sire）将受拥者体内的血液几乎抽干，再注入自己的**绯血**（vitae）。受拥者死亡，然后以不死之身醒来。

初拥不是温柔的授予，而是**谋杀与强暴的混合体**——受拥者在半死半活之间被重塑，与尊长之间留下终身的血缘牵引。这也是为什么合法初拥需要**亲王**批准、需要向城市"报备"：未经批准的**新生儿**（Neonate）本身就是一份待签发的死刑判决书。

### 3.2 饥渴（Hunger）

V5 用**饥渴**取代了旧版的"血池"。角色不会因为喝了血而"回满一条资源条"，而是：饥渴始终潜伏，饥渴骰会污染每一次掷骰，让成功变得危险、让失败变得野蛮。

这意味着**猎食本身就是风险**：饥渴越深，角色越容易被心兽接管，越容易在猎食中留下无法掩盖的尸体，也就越接近避世戒律的红线。

### 3.3 血权（Blood Potency）

**血权**衡量血液的浓度与力量，取代了旧版"世代"作为核心机制的地位（世代的说法在设定中仍被使用，但不承担主要规则功能）。血权越高：能榨取的力量越强、能用血做的越多；同时也意味着**只能靠更强的血液果腹**、更难被普通血液满足、更深的沉睡周期、对猎物更挑剔。

对剧本创作来说，血权是极好的**阶级隐喻**：越古老越强大，也越离不开稀有的资源，越难在这座城市里"低调地活下去"。

### 3.4 共鸣与血质（Resonance / Dyscrasia）

人所饮之血带有情绪色彩，称为**共鸣**：愤怒之人的血、忧郁之人的血、淡漠之人的血、热血之人的血，各有不同。血族长期饮用某一类共鸣的血液，会更容易在对应方向上获得成长，但也可能被这种情绪牵引。

某些猎物体内会凝结出更浓的**血质**（Dyscrasia），饮下后能获得额外的助力。这让"选猎物"从资源问题变成**品味与癖好的问题**——也是极佳的叙事素材：一个角色开始只喝恐惧中的血，意味着什么？

### 3.5 沉睡与终亡（Torpor / Final Death）

血族不会被"打死"得那么干脆。重伤或长时间断食会使其坠入**沉睡**（Torpor）——一种意识模糊、无防备的状态，可能持续数夜，也可能持续一个世纪。沉睡期间被他人发现的后果，足以写成整个剧本的第三幕。

真正不可逆的结束叫**终亡**（Final Death）：阳光、烈焰、斩首、被更强的血族吸榨殆尽，或某些古老而禁忌的手段。

### 3.6 血之弱点速查

| 弱点 | V5 中的处理要点 |
| --- | --- |
| **阳光** | 致命。现代之夜中最难掩盖的死亡方式，也是最容易被说书人用来制造时限的手段。 |
| **火焰** | 依然有效且依然恐怖。旧版剧本常用"纵火"作为高潮，现代之夜仍可用，但要考虑消防与监控。 |
| **木桩** | 在 V5 中，木桩**钉入心脏**主要使血族瘫痪，而非直接杀死——这更适合做成"被抓住"而非"被打败"。 |
| **邀请** | 部分血族受"未受邀不得入内"的古老约束（依设定与氏族而定）。 |
| **计数与强迫症** | 某些长老有"数清撒落的米粒"之类的古老弱点，可用作细节调味。 |
| **饮水与进食** | 无法消化凡俗食物，强行进食会剧烈呕吐。 |

## 4. 心兽、饥渴与人性

### 4.1 心兽（The Beast）

心兽是血族体内那头永远饥饿、永远恐惧、永远愤怒的东西。它不是外来的附体，而是**角色自己**被死亡与饥渴放大到极限的那部分。血族的一生，就是与它长期共处、谈判、欺骗自己说已经驯服了它的一生。

### 4.2 狂乱（Frenzy）

当心兽接管时，角色进入**狂乱**。触发方式主要有三类：

| 类型 | 触发 | 结果倾向 |
| --- | --- | --- |
| **饥渴狂乱**（Hunger Frenzy） | 饥渴过深、闻到鲜血 | 不顾一切地扑向最近的"食物" |
| **愤怒狂乱**（Fury Frenzy） | 被挑衅、被羞辱、被攻击 | 撕碎激怒自己的对象，不达目的不止 |
| **恐惧狂乱**（Terror / Rötschreck） | 火焰、阳光、真正的致命威胁 | 不计代价地逃离，碾压一切挡路者 |

狂乱是本类型游戏里最有效的"失控装置"：它把政治剧本一瞬间变成恐怖剧本，也把玩家最珍视的计划变成一地碎玻璃。

### 4.3 人性、戒条、信念与血锚

V5 的道德机制不是一张固定的"七宗罪清单"，而是由说书人与玩家共同定义的：

- **编年史戒条**（Chronicle Tenets）：整张桌子认同的三条左右的核心准则，例如"绝不滥杀""家人高于一切""秘密不可外泄"。
- **信念**（Convictions）：角色个人的道德支点，可以正当化、甚至凌驾于戒条之上。
- **血锚**（Touchstones）：承载角色人性的人、物或羁绊。血锚受损，人性就摇晃。
- **人性**（Humanity）：被"污点"（Stains）侵蚀的分数。降至零点，角色永久被心兽吞没，成为说书人手中的怪物。

### 4.4 为什么这套机制适合写剧本

它把"道德"从背景设定变成了**主动装置**：

1. 说书人不必禁止玩家做坏事，只需要让坏事留下代价。
2. 玩家自己定义的戒条，比规则书强加的规则更有约束力——因为是玩家亲手写的。
3. 每一次堕落检定都是角色的**内心独白时间**，是免费的情绪高潮。

## 5. 氏族

### 5.1 氏族是什么

**氏族**（Clan）是血族的血统家族。同一氏族的人通常共享：

- 一条**氏族弱点**（Bane）——无法摆脱的诅咒；
- 一组律能倾向——某些律能更容易掌握；
- 一套文化气质与刻板印象——以及围绕这套刻板印象的偏见、笑话与政治标签。

氏族内部会互相歧视、结盟、背叛；跨氏族的联合则往往脆弱且高度政治化。**血统不是命运，但它是最常被当作命运使用的东西。**

### 5.2 秘盟七族

现代之夜中，秘盟（Camarilla）由七个氏族构成：

| 氏族 | 中文常用译名 | 气质关键词 | 典型弱点方向 |
| --- | --- | --- | --- |
| Ventrue | 梵卓 | 王侯、责任、品味、统治欲 | 只能饮用特定类型的血 |
| Toreador | 妥芮朵 | 艺术、美、沉溺、嫉妒 | 面对极致之美会失神 |
| Malkavian | 末卡维 | 疯癫、先知、破碎的洞察 | 永久的精神错乱 |
| Nosferatu | 诺斯费拉图 | 隐匿、情报、畸变、坚韧 | 外貌永久畸变，无法混入人群 |
| Tremere | 睿魔尔 | 仪式、学术、血术、派系纪律 | 血缚与血液相关的结构性束缚 |
| Banu Haqim | 巴努·哈奇姆 | 审判、契约、刺客传统、戒律 | 对血族血液的病态渴望 |
| Lasombra | 拉斯翁布拉 | 阴影、权力、教会式的冷酷野心 | 影像残缺、光与影的不自然 |

> 说明：上表的弱点仅描述方向与叙事表现，具体规则表述以规则书为准。氏族在剧本中的价值，主要不是数值，而是：**当玩家得知对手是某氏族时，他会立刻产生一套合理预期，而你可以选择满足它或推翻它。**

### 5.3 叛党与自由派诸族

**布鲁赫**（Brujah）与**冈格罗**（Gangrel）在 V5 的变局中已大规模脱离秘盟，成为叛党（Anarchs）与自由派的中坚。**塞特追随者**演变为**事工**（The Ministry）后亦归入叛党阵营。

| 氏族 | 气质关键词 | 叙事用途 |
| --- | --- | --- |
| Brujah | 反叛、激情、街头、易怒 | 天生的煽动者与麻烦制造者 |
| Gangrel | 野性、流浪、动物之友、边境 | 与城市的"文明政治"保持距离 |
| The Ministry | 诱惑、信仰、宗教包装的操盘 | 把信仰、欲望与政治搅在一起 |
| Caitiff | 无氏族、被歧视、白手起家 | 最容易被当作弃子与替罪羊 |

### 5.4 独立氏族

不归入秘盟或叛党的氏族，各有自己的议程：

- **赫卡塔**（Hecata）：由多个死亡系血统整合而成，与亡魂、尸体、家族生意打交道；其内部派系林立。
- **拉夫诺**（Ravnos）：幻术、流浪、被大规模迫害后的幸存者群体。
- **萨洛布里**（Salubri）：被污名化的"善者"，稀有、被猎杀、背负血统冤案。
- **茨米谢**（Tzimisce）：血肉、地主、旧式恐怖，多与魔宴相关。

### 5.5 稀血（Thin-Blood）与无氏族

**稀血**是血脉稀薄到不足以算作正式血族的存在。他们力量弱、律能不稳定，却能做出正式血族做不到的事：**白日行走、吃下凡人的食物、使用稀血炼金术**。

在剧本里，稀血是最天然的主题载体：**被所有人歧视、却又最像人的那一群**。他们常常是新生儿团队的镜子，也常常是最先被牺牲的人。

## 6. 派系与权力结构

### 6.1 秘盟（Camarilla）

秘盟是现代之夜最有组织的血族势力，行事风格介于**宫廷、公司董事会与黑手党**之间。它的官方立场是：维护避世戒律，保护血族整体存续，靠传统和纪律对抗猎人与魔宴。

它的实际运作是：**所有人都在往上游，所有人都知道一旦跌落就没人接住。**

**城市官职速查**

| 职位 | 职能 | 剧本用途 |
| --- | --- | --- |
| 亲王（Prince） | 城市最高统治者 | 终极仲裁者；也是最大的靶子 |
| 总管（Seneschal） | 亲王的行政与信息中枢 | 真正的权力常在这里；绝佳的隐藏反派 |
| 元老（Primogen） | 各氏族代表，构成亲王的顾问与制约 | 政治戏的主战场 |
| 治安官（Sheriff） | 执法者，负责追捕违反传统者 | 追捕玩家的第一道实体压力 |
| 猎犬（Hound） | 治安官的爪牙 | 街头追猎与恐吓的执行者 |
| 灾祸（Scourge） | 处理"不合格"的血族（尤其稀血） | 最适合制造道德冲突：他杀的是无辜者 |
| 极乐境守护者（Keeper of Elysium） | 维护极乐境秩序 | 让玩家在最安全的地方失态的裁判 |
| 竖琴手（Harpies） | 舆论与声望的裁决者 | 用流言而非刀锋杀人的人 |

### 6.2 极乐境（Elysium）与血猎（Blood Hunt）

- **极乐境**：约定俗成的中立场所，多半是歌剧院、博物馆、私人俱乐部、画廊。此地**禁止一切暴力**，是政治谈判、交易、羞辱与告白的舞台。破坏极乐境规则等于自绝于社会。
- **血猎**：由亲王宣布的公开猎杀令，所有血族都有义务参与。这是秘盟最重的判决，也是绝佳的高潮装置。

### 6.3 六道传统与秘盟附加戒律

V5 中，血族社会的共同法度大致是六道**传统**：避世戒律（The Masquerade）、领地（Domain）、子嗣（Progeny）、问责（Accounting）、毁灭（Destruction）、款待（Hospitality）。秘盟对其成员另有更严格的附加戒律，例如关于**血之缄默**（Silence of Blood）与**血猎**的规条。

写作提示：**不必逐条列出规则，而要让玩家在违反它们的后果中认识它们。** 一个被"款待"保护的敌人，比一段说明文字更有力。

### 6.4 叛党（Anarchs）

叛党不是统一的组织，而是一群拒绝秘盟等级制的血族的松散联盟。他们通常以**男爵**（Baron）为核心组织领地，靠人情、信誉和暴力维持秩序；也有议会式、投票式甚至纯粹靠拳头说话的变体。

他们的核心主张：**没有亲王，也没有谁的赐权；血族的自治不需要一个从不认可的领导。**

他们最大的弱点同样是真实的：缺乏统一指挥、容易被分化、以及"没有传统约束之后，最强者会做什么"。

### 6.5 魔宴（Sabbat）

魔宴是秘盟的镜像敌人：极端、暴力、以"战斗与信仰"自我定义，用**血祭**（Vaulderie）替代血缚，以**群魔会**（Pack）为单位活动。在现代之夜，其主力被吸引前往中东参与**魔宴圣战**，但在任何城市都可能留下一两个群魔会作为恐怖事件的引爆点。

### 6.6 独立氏族与无派系者

许多血族不属于任何一方。**无派系者**（Autarkis）既不宣誓，也不受保护——他们是最自由的，也是最无人可依的。这种孤独感本身就是极好的剧本材料。

### 6.7 非血族势力

| 势力 | 立场 | 剧本功能 |
| --- | --- | --- |
| **第二审判庭**（Second Inquisition） | 有组织的国家与宗教猎杀力量 | 本时代的终极外部威胁：他们不迷信、有数据库、有预算 |
| 零散猎人 | 个人或小团队 | 灵活的单体威胁，适合做城市里的一颗地雷 |
| **血仆**（Ghouls）与凡人仆从 | 被血喂养的凡人 | 血族的延伸感官与手；也是被剥削的悲剧 |
| 狼人、法师、鬼魂等 | 各自的议程 | 让血族意识到"他们并不是夜里唯一的主人" |
| 凡人社会本身 | 法律、媒体、资本、警察 | 现代之夜最被低估的敌人：监控与记录 |

## 7. 现代之夜的变局

这是本编年史的时代背景。以下事件构成了 V5 世界与旧版世界的分水岭。

### 7.1 噩梦之周与超自然的"曝光"

上世纪末的一场大规模超自然灾难，在亚洲某地造成了大范围破坏与难以解释的记录。它让人类世界的某些机构确信：**传说不是传说。**

### 7.2 第二审判庭的成立

情报机构与宗教猎杀组织合并资源，成立了针对血族的跨部门行动体系。他们拥有：

- 数据能力：金融记录、通信元数据、异常死亡模型；
- 技术能力：无人机、热成像、定向监控；
- 组织能力：跨城市、跨国、按图索骥地清剿庇护所。

**这是"现代之夜"与旧时代的最大分界。** 从前，猎人是孤独的疯子；现在，猎人是一份带预算的工作。

### 7.3 维也纳圣所的陷落

血术氏族的核心研究机构被彻底摧毁。这不仅是人员损失，更是**知识体系**的断裂：某些律能、仪式与传承被永久地打碎或散逸。

### 7.4 召唤（The Beckoning）

年长的强力血族被某种来自中东的呼唤牵引，纷纷离开自己的城市。结果：

- 长老缺位，权力真空；
- **新生儿与年轻血族被迫接管城市**——这让玩家团队有了"就任"的合理路径；
- 城市防御变弱，猎人趁虚而入；
- 留下的人要么太年轻，要么太害怕。

对说书人而言，这是最好用的结构性许可：**让玩家承担超出年龄的责任，并且没人能告诉他们该怎么办。**

### 7.5 魔宴圣战（Gehenna War）

魔宴的主力被卷入中东的宗教战争。他们不在城市里，但他们的阴影还在：留下的信徒、渗透者、以及被他们带走的血族留下的空缺。

### 7.6 信息时代的避世戒律

现代之夜的避世戒律面对前所未有的敌人：

| 传统手段 | 现代之夜的对手 |
| --- | --- |
| 改记忆 | 云端备份、第二台手机、群聊记录 |
| 杀证人 | 社交媒体的定时发布、直播、定位打卡 |
| 换城市 | 车牌识别、人脸识别、银行卡流水 |
| 躲进黑夜 | 无人机、热成像、全天候巡逻 |
| 靠血仆办事 | 血仆也会在聊天软件里留下痕迹 |

**结论**：现代之夜的血族，靠的不是更强的力量，而是更细的管理。而"管理"正是政治戏与恐怖戏的天然接口。

### 7.7 长老缺席时代的三大后果

1. **权力下移**：年轻人上桌，但桌上没有说明书。
2. **保守主义反弹**：越是衰老的血族，越倾向于用旧办法解决新问题。
3. **猎人升级**：外部压力迫使血族重新审视"什么值得为之战斗"。

## 8. 律能总览

**律能**（Discipline）是血族血液中具现的超自然能力。V5 中，每项律能各有若干层级的能力可供选择，某些强力能力需要两项律能交叉（融合）。以下是十一项核心律能及其主题与叙事用途。

| 律能 | 英文 | 主题 | 神智/体质类 | 典型使用者 |
| --- | --- | --- | --- | --- |
| 兽性术 | Animalism | 与兽、与心兽对话 | 神智 | 冈格罗、诺斯费拉图 |
| 观占术 | Auspex | 感知、灵视、读取灵气 | 神智 | 末卡维、妥芮朵 |
| 血术 | Blood Sorcery | 仪式、血之魔法、诅咒 | 血统 | 睿魔尔、巴努·哈奇姆 |
| 迅捷术 | Celerity | 速度、超常反应 | 体质 | 布鲁赫、巴努·哈奇姆 |
| 支配术 | Dominate | 命令、篡改记忆、精神压制 | 神智 | 梵卓、末卡维 |
| 坚韧术 | Fortitude | 耐打、抗性、活下去 | 体质 | 梵卓、冈格罗 |
| 模糊术 | Obfuscate | 隐匿、伪装、被忽视 | 神智 | 诺斯费拉图、末卡维 |
| 湮灭术 | Oblivion | 阴影、亡魂、虚无 | 血统 | 赫卡塔、拉斯翁布拉 |
| 巨力术 | Potence | 绝对的力量 | 体质 | 布鲁赫、诺斯费拉图 |
| 威仪术 | Presence | 魅力、威压、情绪操控 | 神智 | 梵卓、妥芮朵、事工 |
| 变形术 | Protean | 化身、兽形、土与血 | 体质 | 冈格罗 |

另有**稀血炼金术**（Thin-Blood Alchemy）：稀血用以临时模拟其他律能的手段，代价与副作用都很大——非常适合写"穷人版的超自然力量"。

**写作用法**：律能不该只是技能列表，而应当是**人格的外化**。一个以支配术解决一切的人，和一个以威仪术解决一切的人，走到哪里都会散发出完全不同的气味；而一个拥有变形术却拒绝使用的人，本身就是一个可写的故事。

## 9. 城市与领地

### 9.1 城市即角色

在这个游戏里，城市不是背景板，而是**一个会衰老、会死去、会被人争夺的存在**。好的编年史城市应当具备：

1. **一段衰败史**——工业外迁、人口流失、火灾、疫情、经济崩盘；
2. **一张具体的地图**——真实地名、具体街区、可被玩家记住的场所；
3. **三个以上的权力中心**——它们互相制衡，谁都不能单独解决问题；
4. **一个正在发生的危机**——它逼角色做选择，而不是等角色去做选择；
5. **一群有名字的凡人**——猎食对象一旦有名字，猎食就变成了道德抉择。

### 9.2 领地（Domain）与猎食权

领地是血族政治最实在的货币。谁在哪些街区可以猎食，直接决定谁能活到明天。此处的规则通常不是法律，而是**默契 + 威慑 + 历史投资**。

领地冲突是最好用的剧本引擎之一，因为它同时触发三条压力线：生存（食物）、政治（主权）、人性（为食物而杀人）。

### 9.3 一张可复用的城市政治骨架

| 位置 | 角色功能 | 缺位时的后果 |
| --- | --- | --- |
| 王座 | 名义上的仲裁者 | 强者各自称王，弱者被瓜分 |
| 长老 | 既有利益的守成者 | 无人记得传统，也无人约束暴力 |
| 反叛者 | 挑战现状的人 | 一切原样运转，只是没人再谈论它 |
| 外来者 | 打破平衡的变量 | 本地人继续在旧规则里互相消耗 |
| 猎人 | 外部倒计时 | 血族把全部精力用于内斗，直到为时已晚 |
| 凡人 | 资源与代价 | 城市变成真正的鬼城，血族随之饿死 |

## 10. 血族生活实务

### 10.1 庇护所（Haven）

白天的安身之处。现代之夜的关键词：**电子门禁、租约记录、邻居的摄像头、快递员、物业**。庇护所被发现的恐怖程度，远高于一次战斗失败。

### 10.2 猎食者类型（Predator Type）

V5 用"猎食者类型"定义角色的进食风格与人际网络（例如在夜店里挑选猎物、在街头暴力抢劫、在医院接触病患、靠社交网络筛选目标、以艺术圈为猎场等）。它同时提供技能、关系与道德倾向，是**最快把"角色是什么人"翻译成"角色如何吃"的工具**，也是编写角色背景时最好用的抓手。

### 10.3 血仆、牧群与血偶

| 类别 | 定义 | 剧本含义 |
| --- | --- | --- |
| 血仆（Ghoul） | 长期饮用血族血液的凡人，获得超常力量与缓慢衰老 | 忠诚、依赖、被剥削；最容易被写成人性镜面 |
| 牧群（Herd） | 稳定的供血人群 | 资源，也是弱点：他们会被敌人找到 |
| 血偶（Blood Doll） | 被吸食并沉溺其中的凡人 | 自愿的受害者；最能体现"控制"的温柔与暴力 |

### 10.4 血缚（Blood Bond）

三次饮用同一血族的血，即可形成**血缚**：受缚者会对缚主产生压倒性的依恋与忠诚。这是血族世界最有效的控制手段，也是本类型剧本里最锋利的伦理武器：**被血缚的人甚至无法确定自己的爱是真的。**

### 10.5 吸榨（Diablerie / Amaranth）

吸干另一位血族直至终亡，可以掠夺其力量、甚至降低自己的血统年龄。这是血族社会公认的重罪，也是最具诱惑力的禁忌——它让"变强"与"杀人"变成同一件事。

### 10.6 情报、通讯与债务

血族社会的货币有三种：**血、恩情、情报**。现代之夜让情报的流通变快，也让谎言的传播变快。设计剧本时，一个流传中的错误流言往往比一份准确的情报更有用。

## 11. 主题与基调工具箱

### 11.1 六个可直接使用的主题句

1. **代价**：为了活下去，你愿意失去什么？
2. **归属**：你是谁的？你属于哪个派系、哪个人、哪段过去？
3. **记忆**：你记得的那个自己，还在吗？
4. **共谋**：你明知这套制度有问题，但你从中获利。
5. **衰亡**：一座城市、一个家族、一个人的不可逆的衰退。
6. **自由的幻觉**：你以为自己在做选择，其实你在执行别人的剧本。

### 11.2 现代之夜专属的恐怖素材

- 社交网络上流传的、不该存在的偷拍视频；
- 一位"已经死了"的老客户在聊天软件里发来消息；
- 血库、外卖平台、深夜信贷、代驾、共享租房——现代猎食基础设施；
- 无人驾驶车辆、无人配送——它们不会害怕，也不会忘记；
- 一张十年前的家庭合影里，出现了不该出现的人；
- 医院的电子病历里，一份从不凝固的血液样本；
- 算法比你的尊长更早发现你是血族。

### 11.3 三种可直接切换的基调

| 基调 | 关键词 | 适合的剧情 |
| --- | --- | --- |
| **宫廷剧** | 礼仪、债务、羞辱、结盟 | 极乐境里的谈判、元老选举、亲王更替 |
| **街头剧** | 生存、地盘、暴力、忠诚 | 领地对峙、猎场争夺、帮派与警察 |
| **恐怖剧** | 失控、饥饿、监控、代价 | 狂乱、猎人清剿、庇护所暴露 |

成熟的编年史通常在同一夜里切换三者：谈判以羞辱告终，羞辱引发暴力，暴力引来猎人。

## 13. 新旧版本差异与移植提示

本目录下的三份演示剧本（`血之诞生`、`尘归尘`、`土归土`）来自 V5 之前的版本，其结构与技法是通用的，但**术语与机制需要换算**。详见 `scenario-writing-and-structure-notes.md`，此处只列最关键的换算表：

| 旧版写法 | V5 中的处理 |
| --- | --- |
| 血池（Blood Pool）点数管理 | 改为**饥渴骰**：不再"消耗资源"，而是"承受污染" |
| 世代（Generation）决定上限 | 改为**血权**（Blood Potency） |
| 本性 / 表性（Nature / Demeanor） | V5 无此配对；改用**信念、血锚、猎食者类型、触发的强迫症**来刻画人格 |
| 难度值 + 固定成功数 | 保留，但注意 V5 的判定基准与骰池构成不同 |
| 律能按点数购买 | 改为**按层级选取具体能力**，并存在融合能力 |
| 人性固定罪目表 | 改为**编年史戒条 + 玩家自定义信念** |
| 木桩可杀 | 改为**木桩通常是瘫痪**，抓人比杀人更符合现代之夜 |
| 纵火作为常用结局 | 现代之夜需要额外考虑消防、监控、保险与新闻 |
| 猎人多为孤狼 | 加入**第二审判庭**：有预算、有数据库、有跨城协调 |

### 移植三原则

1. **保留结构，替换术语**：三份材料的场景骨架、NPC 动机设计与检定结果分级，几乎可以原样使用。
2. **提高外部压力**：把旧版"某位长老的阴谋"升级为"某位长老的阴谋 + 一个正在逼近的猎人小组"。
3. **让代价可见**：V5 的机制本身就是为"代价"服务的，任何旧版里"顺手就做掉"的暴力，都应当留下痕迹。
