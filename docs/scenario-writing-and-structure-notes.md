## 1. 三份材料档案

三份文件均为爱好者中文翻译，译者为同一人，非官方出版物。

| 文件 | 推断的英文原名 | 版本与年代 | 提取后纯文本量 | 宏观结构 | 场景数 | 建议规模 |
| --- | --- | --- | --- | --- | --- | --- |
| `血之诞生 中文翻译.docx` | Blood Nativity（**推断，待核**） | 早期版本。文中使用血池与世代，译者注明确称其为"初版模组" | 约 2.6 万字符 | 角色表（前置）+ 序幕 + 五幕 | 5 | 3–4 名玩家 + 1 名说书人 |
| `尘归尘 中文翻译.docx` | Ashes to Ashes（**推断，待核**） | 1991 年，VTM 最早发布的模组之一，译者称依"二版规则书" | 约 7.2 万字符 | 引言 + 主题/阵营/情绪 + 五章 + 十九章 + 故事思维导图 + 后日谈 | 19 | 未标明，按内容约 4–6 人 |
| `土归土 中文翻译.docx` | Dust to Dust（**推断，待核**） | V20（2014 年前后），《尘归尘》的正式续作 | 约 4.4 万字符 | 引言 + 基础设置 + 九场景 + 后日谈与经验 | 9 | 建议等级 体能3/社交3/心智3，经验 0–35 |

### 三者的关系

- `尘归尘` 是这条线的起点：新生儿从加里市被派往芝加哥，卷入亲王失踪案。
- `土归土` 是二十年后的续作：同一座加里市，人口流失、城市濒死，新一代角色面对的是"衰亡之后怎么办"。
- `血之诞生` 与另两者无关，是**独立的教学型入门故事**，重点不同：它不追求政治复杂度，而是把玩家从凡人一路带到新生吸血鬼，顺路教完核心规则。

这三份材料恰好覆盖了三种截然不同的编年史设计思路，因此非常适合作为技法参照系。

## 2. 阅读与引用注意事项

1. **版本错位**：三份材料全部早于 V5，机制术语（血池、世代、本性/表性、按点数购买律能）与 V5 不同。**结构与技法可通用，数值必须换算。**
2. **译者命名不一致**：`土归土` 的正文里出现一处边栏，把本作自身的内容称为《尘归尘》，属于译者笔误。引用时请以章节标题为准，必要时回查英文原文。
3. **译者注的价值**：译文中夹有大量译者注（版本差异、术语考据、规则页码提醒、数值勘误）。这些注记本身就是极好的"跨版本移植踩坑清单"，建议在改编时逐条对照。
4. **规则页码会失效**：三份材料都直接引用规则书页码（狩猎规则、战斗规则、狂乱规则、劣势与优势等）。这是面向"手边有书的说书人"的写法，改编到 V5 时必须重新定位。

## 3. 共通的十四项写作风格

### 风格一：说书人优先的第二人称指导

全文以"你"直接对说书人讲话，且不掩饰这是在给指令。作者会明确写出"你应该做什么""不要让玩家……""请确保……"。

**价值**：降低说书人的认知负担。说书人翻开任意一页，都能立刻知道自己该干什么、该渲染什么、该提防什么。

**复刻要点**：写作时假设读者是**第一次带这个本**的人，而不是作者自己。

### 风格二：场景段落的固定功能序

三份材料各自固定了一套小节顺序，读者读第二遍时就不需要重新适应：

| 材料 | 场景小节顺序 |
| --- | --- |
| `血之诞生` | 情节 → 场景设定 → 对话（以"幕"为单位） |
| `尘归尘` | 情节 → 背景 → 戏剧 → 对话 → 角色（顺序略有浮动） |
| `土归土` | 概述 → 描述 → 说书人目标 → 角色目标 → 行动 → 结果 |

**价值**：结构一致性 = 查阅效率。带团中途临时翻书时，能按位置直接找到需要的那一段。

**复刻要点**：选一套顺序，然后**每一场都严格照用**，不要中途换风格。

### 风格三：边栏承载规则与世界观科普

`血之诞生` 把教学任务全部放进边栏，包括：血族政治、支配术律能、氏族、血仆、初拥、检定、狂乱。正文只管推进故事，边栏负责在需要的时刻教规则。

**价值**：这是"边玩边教"的最优解——玩家不会在读设定时走神，因为设定正好出现在他们需要它的那一秒。

**复刻要点**：每个边栏只讲一件事，位置紧贴它被用到的场景。

### 风格四：NPC 的"五段式"档案

`尘归尘` 与 `土归土` 严格遵循同一套 NPC 写法：

1. **标志性台词**（`土归土` 放在最前，且用引号罗列两三句）
2. **背景故事**
3. **形象描写**（外观、穿着、气味、动作习惯）
4. **叙事 / 扮演提示**（说书人该怎么演他）
5. **数据**（属性、技能、律能、背景、美德/人性、意志）

**价值**：把台词放在最前，是因为说书人最需要的不是数值，而是"这个人一开口是什么味道"。数据放最后，因为它最不重要。

**复刻要点**：写完 NPC 后，先问自己"他的第一句话是什么"。答不出来，说明这个人还没立起来。

### 风格五：分级成功结果表

`土归土` 的标志性技法，每个关键行动都给出完整的结果分层：

> 骰池 + 难度 → 不利因素 / 有利因素 → 大失败 / 失败 / 1 成功 / 3 成功 / 5 成功

**价值**：这是给说书人的"即兴授权脚手架"。它同时解决三件事：判定怎么设、失败该怎么处理、成功到什么程度算超额。

**复刻要点**：不必每个检定都写五档，但**每个可能改变剧情走向的检定**都应该写。

### 风格六：有利/不利因素清单

同一检定的难度不再是拍脑袋决定的，而是由清单加减得出：角色是否饥渴、是否穿了戏服、是否有相关专长、是否处于敌人领地……

**价值**：把"环境"翻译成"数值"，同时向说书人示范了该怎么描述这些环境。

**复刻要点**：因素本身要有画面感（"角色没有进行僵尸装扮"比"角色未准备"好得多）。

### 风格七：开篇引文定调

`土归土` 用雪莱《奥西曼迭斯》的诗句开场，与"衰亡之城"的主题直接呼应；`尘归尘` 用《公祷书》中"尘归尘、土归土"的葬礼经文作边栏，同时解释书名。

**价值**：一行引文比一段说明更快地把读者送入正确情绪。

**复刻要点**：引文要能同时呼应**主题**与**书名**。

### 风格八：独立的"主题"与"基调"章节

`土归土` 设专章讲"核心主题是复苏与前行"以及"基调是灰败"；`尘归尘` 设"主题""情绪""选择阵营"三节。

**价值**：这两章不是说给玩家听的，而是**给说书人校准用**。它明确了所有场景应当共同指向什么。

**复刻要点**：主题章写一句话，基调章写一种颜色、一种气候、一种声音。

### 风格九：直接引用规则页码

作者默认说书人手边有规则书，于是写"详见核心书第 X 页"，而不是把规则抄一遍。

**价值**：大幅压缩篇幅。缺点是跨版本立即失效。

**复刻要点**：如果目标读者版本与你一致，就用这种方式；否则改为"此处适用 V5 的某某规则"。

### 风格十：同一素材的两种密度

`土归土` 专设一个边栏，说明本作曾在一次大会上以五小时的独立短剧形式演出，并逐条列出**如何删减**以复现那次的版本（削弱某条对立线、砍掉四个场景、把焦点集中到单条阴谋上）。

**价值**：极其实用的"减法说明书"。同一份文本可以按"三小时版"或"三次团版"运行。

**复刻要点**：为你的剧本附一节"如果只有一次聚会时间，砍哪几场、保留哪条线"。

### 风格十一：反复申明改编权归说书人

`尘归尘` 用整节篇幅反复强调"你必须改变它，改得越多越能理解它"；`土归土` 明说"加里市的命运终由你执笔书写"。

**价值**：这是一次**授权**。它消解说书人"我是不是跑错了"的焦虑，也鼓励他们按自己桌面的需求改写。

**复刻要点**：至少在开头与结尾各写一次这类授权语。

### 风格十二：显式的"可跳过"设计

`尘归尘` 明说玩家不可能走完所有场景，鼓励说书人"如果故事结束时玩家跳过了我们描述的一半场景，请随意在其他地方使用这些点子"；`土归土` 则在每个场景末尾直接给出"接下来可以推进到哪两三个场景"。

**价值**：把"废稿"重新定义为"备用素材库"，同时降低说书人的完美主义压力。

**复刻要点**：每个场景结尾写清后继路径，并在总览里注明哪些是可选的。

### 风格十三：双重真相与幕后结构

`尘归尘` 明说真正的线索是"两位玛土撒拉之间的战争"，而玩家几乎不可能看到全貌；`土归土` 也有一个"玩家看不见的更大棋局"层。

**价值**：这让剧本在第二次阅读时仍然成立，也让说书人在即兴时可以随时用"幕后另有其人"来解释任何异常。

**复刻要点**：为你的剧本写一份**只有说书人能看的真相时间线**（`土归土` 称之为"基础设置"），并明确哪些内容永远不该被玩家看到。

### 风格十四：三方并行的势力设计

`土归土` 的三位长老各有独立计划、各有资源短板，于是自然衍生出"三方同时雇佣玩家"的任务大厅场景；`尘归尘` 则有秘盟、叛党、猎人三方拉扯。

**价值**：三方结构比两方对立更耐玩——两方对立时玩家只能选边，三方共存时玩家可以周旋、可以抬价、可以让别人互相消耗。

**复刻要点**：每方只写三样东西：**想要什么、能付出什么、绝对不能接受什么**。

## 4. 三种编年史骨架

### 4.1 线性教学式 —— `血之诞生`

**结构**

```
角色表（前置：所有 NPC 的完整档案与选择子嗣的标准）
  ↓
序幕：说书人信息（前情提要 + 邀请函 + 抵达钩子）
  ↓
第一幕：公开场合的伪装晚宴      ← 教"角色扮演"与"观察"
第二幕：初拥                    ← 教"转化"与"尊长-子嗣关系"
第三幕：觉醒                    ← 教"避世戒律、领地、猎食规则"
第四幕：不可遏止的饥渴          ← 教"猎食"与"狂乱"，本幕是道德高压区
第五幕：逮捕                    ← 教"后果"，并给出两种收束
  ↓
两种结局：合规→受封中立领地，开启编年史；失手→放逐或终结
```

**设计特征**

- **严格线性**，一场接一场，没有分支地图。
- **前置角色表**：把全部 NPC（含数值、选人标准）放在开篇，让说书人先熟悉人物，再读剧情。
- **每一幕对应一到两个机制教学点**，边栏同步讲解。
- **NPC 的"择嗣标准"就是给玩家的角色扮演提示卡**：音乐人找伯顿、政治动物找伊莎贝拉、革命者找达利利、孤僻的幸存者找 RJ。玩家在社交中自然被"认领"，转化成个人化的转化体验。
- **结尾双分支**，且分支的触发条件是**玩家在前四幕的行为累积**（是否留下尸体、是否打破避世戒律）。

**适用场合**：全新玩家、全新说书人、单次聚会、需要一次性展示全部核心机制的场合。

**复刻要点**

1. 让玩家先以**凡人身份**跑一段，再转化。这一步是这套设计的灵魂。
2. 把规则拆成边栏，位置紧贴使用点。
3. 每个 NPC 给一条"他会选什么样的人"，等于免费送给玩家一张个性钩子。
4. 结尾用"前四幕的行为账本"结算结局。

### 4.2 节点地图式 —— `尘归尘`

**结构**

```
引言 / 如何使用 / 主题 / 选择阵营 / 情绪 / 阴谋总纲
  ↓
故事思维导图（19 个场景的节点与连线，标注哪些可以通向别处）
  ↓
第一章（加里市：导入与派遣）
第二章（芝加哥：俱乐部 → 地下酒吧 → 叛党集会 → 假亲王 → 逃脱）
第三章（审问、搜查、线索、盖尔人、血之样本）
第四章（警局、小报、猎人）
第五章（地狱牧场 → 袭击 → 仪式 → 鼠道 → 落幕）
  ↓
幕后真相层（两位玛土撒拉的战争 / 反派的第一人称闪回）
  ↓
后日谈与多重结局
```

**设计特征**

- **有主脊，但每个节点都有出口**：作者明确标注"这个箭头指向别处"，即故事很可能从预设轨道上跑开。
- **调查驱动**：推进力来自"下一条线索在哪里"，而不是"谁下了命令"。因此节奏主要由玩家的推理速度决定。
- **冒名顶替与身份反转**：玩家见到的"亲王"其实是他人假扮；他们要找的尸体其实不是目标；他们要营救的对象其实是沉睡的古老存在。**每一章都推翻前一章的一个前提**。
- **可选的反派闪回**：作者建议让玩家直接扮演反派，甚至可以让其中一名玩家成为反派本人。这是本材料最大胆的技法。
- **结局开放且可分裂**：目标人物的生死由玩家决定，并直接改变后续编年史的格局。

**适用场合**：有经验的桌、长编年史中的一章、喜欢调查与政治阴谋的玩家、愿意接受非线性推进的说书人。

**复刻要点**

1. **先画思维导图，再写场景**。先确定节点与连线，再填内容。
2. 每个场景准备一个"如果玩家不去这里"的替代路径。
3. 每一章安排一次**前提推翻**，让玩家的认知持续被修正。
4. 考虑设置一层玩家看不到的幕后真相。

### 4.3 沙盒事件式 —— `土归土`

**结构**

```
引言 / 简介 / 背景故事 / 主题 / 基调
  ↓
"编年史的一章" 与 "自成一体"（两种使用说明书）
  ↓
基础设置：图谋与目标（每个 NPC 一句话诉求）+ 引入角色的六条动机 + 登场角色档案
  ↓
九个场景（不强制顺序，各自给出后继路径）
  欢迎来到加里 / 猎人 / 邀约 / 僵尸游行 / 尘中归来
  / 杂耍课 / 无牙猎犬 / 加里的临终喘息 / 明日之夜
  ↓
后日谈（由 NPC 作为引导者，带玩家回顾） + 经验与奖励
```

**设计特征**

- **作者亲口否认这是线性剧本**，自称呈现的是"设定框架 + 角色 + 宏观局势 + 若干触发事件"，并用"沙盒模式"作比。
- **说书人目标 / 角色目标 双栏对齐**：每个场景同时给出"说书人想达成什么"与"角色想达成什么"。这一对标注极其实用——它让说书人在玩家跑偏时，仍然知道自己该保住哪一个核心。
- **描述段可直接朗读**：每个场景的"描述"是一段第二人称、现在时、充满嗅觉与温度的画面文本，说书人可以照着念。
- **场景末尾给出后继路径**："若发生 A 推进到场景 X，若发生 B 推进到场景 Y。"这使得沙盒仍然有骨架。
- **任务大厅设计**："邀约"一场让三位长老分别开出条件、报酬与要求，且明说三项任务并不互斥。这是让玩家自行分配注意力的高效装置。
- **可乱序的势力对抗**：两位长老的对立场景可以插在任意位置，作者明确说"也可以增补中间场景"。
- **开放式收束**：终章由一位猎人与玩家对谈，用提问代替结局，把"接下来会发生什么"交还桌面。

**适用场合**：喜欢自主行动的桌、能接受说书人大量即兴的组、想用同一座城市连续跑多次聚会的编年史。

**复刻要点**

1. 把所有 NPC 的诉求写成一页纸的清单——这是沙盒唯一的燃料。
2. 每个场景写两到三个后继路径，形成一张松散的网。
3. 给每个场景准备一段可直接朗读的画面文本。
4. 准备六条以上"角色为什么会来到这里"的动机，让玩家开局就有位置。
5. 结尾用一场对话式复盘代替战斗式高潮。

### 4.4 三种骨架对照

| 维度 | 线性教学式（`血之诞生`） | 节点地图式（`尘归尘`） | 沙盒事件式（`土归土`） |
| --- | --- | --- | --- |
| 推进力 | 说书人推动事件 | 玩家追查线索 | 玩家自主行动 + 势力互相拉扯 |
| 结构弹性 | 低 | 中 | 高 |
| 说书人准备量 | 低 | 中高 | 高（需要即兴能力） |
| 玩家自由度 | 低（但沉浸深） | 中 | 高 |
| 最容易失败的环节 | 玩家觉得被牵着走 | 玩家卡在某个线索上 | 玩家失去方向、各走各的 |
| 补救手段 | 明确每幕的教学目标 | 准备"线索兜底"的备选渠道 | 让 NPC 主动找上门 |
| 体量 | 1 次聚会 | 2–4 次聚会 | 1–3 次聚会 |
| 最佳用途 | 新手入门、教学 | 长篇编年史中的一章 | 长期沙盒的舞台 |

**混合建议**：本编年史最实用的做法是——**用沙盒式的框架承载节点式的章节，再用线性式的教学场景开场**。即：

1. 第一次跑团用线性教学式（一个"初拥之夜"），确保所有人进入状态；
2. 之后用节点地图式推进主线阴谋；
3. 全程用沙盒式的框架（势力目标清单 + 后继路径）承接玩家的自由行动。

## 5. 场景写法解剖

### 5.1 `尘归尘` 型：五段式

| 小节 | 内容 | 给谁看 |
| --- | --- | --- |
| **情节** | 这一场会发生什么，以及幕后同时在发生什么 | 说书人 |
| **背景** | 地点本身：建筑、气味、光线、藏着的线索 | 说书人（可摘取朗读） |
| **戏剧** | 冲突、动作场面、突发事件、可能的暴力 | 说书人 |
| **对话** | 哪位 NPC 会说什么、愿意透露多少、真正知道多少 | 说书人 |
| **角色** | 本场出场的 NPC 及其数据 | 说书人 |

**优点**：分工清晰，特别适合**调查与对话为主**的场景。注意其"对话"一节会明确区分"NPC 愿意说什么"与"NPC 真正知道什么"——这是防止说书人无意中泄底的关键设计。

**缺点**：缺少对判定难度的量化指导，说书人需要自行拍板。

### 5.2 `土归土` 型：六段式 + 检定块

| 小节 | 内容 | 给谁看 |
| --- | --- | --- |
| **概述** | 一句话讲清本场要达成什么，并标注心智/体能/社交的难度档 | 说书人 |
| **描述** | 一段可直接朗读的画面文本 | 说书人 → 玩家 |
| **说书人目标** | 本场在叙事上必须保住的东西 | 说书人 |
| **角色目标** | 玩家在本场大致想得到什么 | 说书人 |
| **行动** | 关键检定：骰池、难度、有利/不利因素、五档结果 | 说书人 |
| **结果** | 本场可能的收束方式，以及后继场景 | 说书人 |

**优点**：信息密度更高，可直接上手；五档结果让即兴有据可依；"说书人目标/角色目标"的对齐让跑偏时仍有方向。

**缺点**：写作量大；机械感更强，说书人若不朗读"描述"段，画面感会流失。

### 5.3 `血之诞生` 型：教学式

| 小节 | 内容 | 给谁看 |
| --- | --- | --- |
| **情节** | 本幕的目的与允许玩家自由发挥的范围 | 说书人 |
| **场景设定** | 场地的物理布局与在场人物 | 说书人 |
| **对话** | 逐个 NPC 列出：他会说什么、他在找什么样的子嗣、他会如何试探 | 说书人 |
| **边栏** | 本幕需要的规则与世界观知识 | 说书人（必要时转述给玩家） |

**优点**：教学意图极其明确；NPC 的"择嗣标准"一举两得——既是 NPC 动机，也是给玩家的角色塑造提示。

**缺点**：几乎不给骰子与判定细节，完全依赖说书人经验；且首幕依赖玩家愿意认真演"凡人"。

### 5.4 结论：怎么选

- 场景以**对话与调查**为主 → 用 `尘归尘` 型。
- 场景以**行动与冲突**为主 → 用 `土归土` 型。
- 场景承担**教学任务** → 用 `血之诞生` 型，并配边栏。

实战中，一个成熟剧本会**混用**：主线推进用六段式，社交调查用五段式，开篇与教学用教学式。

## 6. 可直接复用的模板

### 6.1 模组骨架模板

```markdown
# 剧本名

## 一句话前提
## 资料来源与版本说明
## 如何使用本剧本（碎片取用 / 完整跑 / 编年史的一章 / 自成一体）
## 主题（一句话）
## 基调（一种颜色、一种气候、一种声音）
## 背景故事：真相时间线（说书人限定）
## 势力图谋与目标（每方三行：想要什么 / 能付出什么 / 绝不接受什么）
## 登场角色（使用 NPC 模板）
## 引入角色（六条以上入城/入局动机）
## 场景总览与流转图
## 场景（逐场，使用场景模板）
## 边栏（规则与世界观补丁，贴在需要的位置）
## 后日谈（多重结局与后果清单）
## 经验与奖励
## 附录：如果只有一次聚会时间，怎么砍
```

```markdown
#### 结果与后继

- 若玩家完全回避本场 → 备选方案 Z
```

## 7. 移植到 V5《现代之夜》的注意点

### 7.1 术语与机制换算

| 旧版写法 | V5 处理 |
| --- | --- |
| 血池点数 | **饥渴骰**。资源管理变成风险累积，猎食场面自动升级为紧张场面 |
| 世代 | **血权**（Blood Potency）；世代作为背景用语保留 |
| 本性 / 表性 | 删除。改用**信念、血锚、猎食者类型、氏族强迫症** |
| 律能按点数购买 | 按层级选取具体能力，并可用**融合能力** |
| 固定的人性罪目表 | **编年史戒条 + 玩家自定义信念 + 污点与悔恨** |
| 木桩可致终亡 | 木桩通常是**瘫痪**，因此"抓活口"比"打死"更符合 V5 |
| 孤狼猎人 | 升级为**第二审判庭**：有预算、有数据库、有跨城协调 |
| 火与阳光作为主要死法 | 依然有效，但现代之夜要额外考虑消防、监控、保险与新闻 |

### 7.2 三份材料中最值得直接迁移的技法

1. **NPC 的标志性台词**（`土归土`）——写 NPC 时先写他的第一句话。
2. **五档检定结果**（`土归土`）——即兴的骨架，尤其适合 V5 的混乱大成功与兽性大失败。
3. **说书人目标 / 角色目标双栏**（`土归土`）——跑偏时的锚点。
4. **场景末尾的后继路径**（`土归土`）——让沙盒仍有网。
5. **可乱序的势力对抗**（`土归土`）——三位长老的对立可插在任意位置。
6. **冒名顶替与身份反转**（`尘归尘`）——每一章推翻一次前提。
7. **反派闪回**（`尘归尘`）——让玩家去演反派，是性价比极高的高级技法。
8. **前置角色表与择嗣标准**（`血之诞生`）——一次写好，全场通用。
9. **边栏渐进教学**（`血之诞生`）——新手桌的必备。
10. **两种密度的删减说明**（`土归土`）——写作时顺手写好"短版怎么跑"。

### 7.3 现代之夜专属的增补方向

旧版剧本的外部压力主要来自血族内部与孤狼猎人。移植到 V5 时，建议补上：

- **第二审判庭的倒计时**：一条从开场就存在的、缓慢收紧的外部压力线。
- **通讯痕迹**：玩家每一次使用手机、转账、叫车都可能留下线索。
- **社交媒体**：避世戒律的破裂不再只是"有人看见了"，而是"有人直播了"。
- **匿名化与数字身份**：血族在现代社会维持多个合法身份的成本与风险。

### 7.4 移植三原则

1. **保留结构，替换术语**：场景骨架、NPC 动机、检定分层几乎可以原样搬用。
2. **提高外部压力**：把"某位长老的阴谋"升级为"某位长老的阴谋 + 一个正在逼近的猎人小组"。
3. **让代价可见**：V5 的机制为"代价"而生；旧版里"顺手就做掉"的暴力，都应当留下痕迹。

## 8. 写作自检清单

写完一幕／一场之后，逐条核对：

- [ ] 开头有没有一句话前提？
- [ ] 有没有明确的主题句与基调描述？
- [ ] 每个 NPC 有没有标志性台词？
- [ ] 每个 NPC 有没有写清"绝对不会承认的那件事"？
- [ ] 每场是否同时写了"说书人目标"与"角色目标"？
- [ ] 有没有一段可以直接朗读的画面文本？
- [ ] 关键检定有没有给骰池、难度与五档结果？
- [ ] 有利/不利因素是否有画面感，而不是抽象的加减值？
- [ ] 是否给出了场景之间的后继路径？
- [ ] 是否准备了"玩家绕过本场"的备选方案？
- [ ] 是否有说书人限定、永不外泄的真相层？
- [ ] 结尾是否有多个结局与各自的后果清单？
- [ ] 是否有后日谈与经验分配建议？
- [ ] 规则引用是否标注了版本？
- [ ] 是否给新手留了边栏？
- [ ] 是否明确写出了"改编权在说书人手上"？
- [ ] 是否写了"只有一次聚会时间怎么砍"的短版方案？
- [ ] 三位以上势力是否都写清了"想要什么 / 能付出什么 / 绝不接受什么"？
