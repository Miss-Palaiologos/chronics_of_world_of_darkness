## 场景描写

*可直接朗读。段落之间留白，不要一口气念完。*

宵禁第三夜，20:40。两支队伍从两个方向靠近旧城。

主权派的队伍从东侧来，联盟派的队伍从西侧来。一边喊「全文公开，追责签字者」，一边喊「公开附件，谈判继续」。

断电、封路，还有一辆在路口抛锚的巴士。为了避开封锁，两队都选择了同一条捷径——旧站台。

20:50，玩家看见一个人离开队伍。他没有举横幅，拐进小巷，往地下走。

小巷里停着一辆没有标志的军用吉普，车顶一架无人机正在待机。<sup>1</sup>

玩家跟着他下去，先到旧站台。

站台尽头有五名血仆，五桶燃料，和一条只有一个方向的通道。

三到五回合之后，两支队伍会从两个入口同时进来。

先是沉默。然后是推搡。然后是踩踏。

特警封住两个出口，开始抓人。

如果地上有尸体，或者火被点燃，宪兵的车会从另一个方向开进来。

**如果玩家什么都不做，下一幕开始时，城市已经进入戒严。**

## 暴力

### 旧站台约束了什么

**这一段的作用不是描写，是拿走玩家的选项。** 旧站台不是用来战斗的，是用来让两群人无法同时退出的。

| 被拿走的东西 | 怎么拿走的 |
| --- | --- |
| **东侧坡道** | **主权派从这里下来。** 坡道很陡，一旦有人回头，后面的人会把他们推回来。 |
| **西侧楼梯** | **联盟派从这里下来。** 楼梯很窄，两侧是贴满旧广告的瓷砖墙。 |
| **站台中段** | **两支队伍只能在这里迎面撞上。** 中间没有隔断，也没有第二条横通道。 |
| **火** | **这是魔宴的手段。** 燃料已经被搬进来，烟会往两个入口倒灌。 |
| **血** | **没有风、没有雨、没有排水。** 血不会干，而它会变成宪兵进场的理由。 |
| **时间** | **三到五回合。** 说书人决定两队何时出现，玩家无法把时间停下来。 |
| **出口** | **特警会封住两个入口。** 玩家可以出去，但队伍不能全部出去。 |

**所以玩家真正能做的不是阻止两队相撞，而是决定特警进场时地上有没有尸体，以及宪兵有没有理由开枪。**

> **这一段的存在理由**：模糊术加燃烧瓶能解决掉任何一个「一屋子你打不过、又不该杀的人」的场景。所以每一场暴力的问题都刻意**不是**打倒对手——**打倒对手永远有更快的办法，而那样办法解决不了这一场。**

### 第一段 · 小巷与旧站台

**玩家看见一个人离开队伍。** 他没有举横幅，也没有跟任何人说话，只是拐进一条小巷，往封闭的旧站台下去。

小巷里停着一辆没有标志的吉普车，车顶有一架无人机正在待机。车上的人不下车，而脚上穿的是军靴。

**发现它的方式——三条**

- **观察**：那个人离开队伍时没有犹豫。他知道自己要去哪，也知道几点前必须到。
- **嗅觉**：他身上有绯血的味道，而绯血的味道从巷子一路延伸到旧站台。
- **侦查**：巷口有一架无人机和一辆军用吉普。他们不是来抓玩家的——他们是在等两队人撞上。

**跟着他下去，玩家会先到旧站台。** 不跟，两支队伍仍会自己撞上；只是没有人知道地下已经准备好火和尸体。

#### 真相（说书人限定）

血仆的任务不是杀玩家，而是把两支游行的恐惧推到临界点。旧站台是两支队伍今晚唯一会自然相遇的地点：一队从东侧坡道下来，一队从西侧楼梯下来，中间只有一条站台。

**注意**：**这不是警方驱赶。** 是断电路线、封路、抛锚的巴士和两队的捷径选择，恰好把所有人送到同一个地方。

### 第二段 · 旧站台

**玩家下到旧站台后，会看见五名血仆在站台尽头搬运燃料。** 他们没有立刻攻击玩家，因为他们的目标从来不是玩家——是即将从两端进来的两支队伍。

玩家必须在两队相撞前解决血仆和燃料。**解决得太干净，特警会封站抓人；留下尸体或火，宪兵就会开枪。**

#### 对手

**是谁**：五名血仆——被喂过血、负责把旧站台变成恐慌现场的人

**真相**：他们不知道自己是弃子。十三告诉他们，只要火起来，城市就会停下来。

- **模板**：血仆（宵禁期间被连续喂血）
- **属性**：力量 3　敏捷 3　耐力 3
- **技能**：格斗 2　运动 2　警觉 2
- **备注**：受伤不会让他们退缩。他们感觉不到疼，而这正是他们可怕的地方。

**人数**：五个人，五桶燃料，两个入口，约三到五回合后两支队伍会同时进场。

#### 这一战为什么逼出吸血鬼规则

- **激励检定**：想不打死人，就得用律能或血涌；每用一次律能、每加一次血涌、每回一档伤，都要做一次激励检定。失败则饥渴 +1。
- **饥渴之后不会降下来**：打完这一场，玩家一定是渴的。而他们身边是即将涌入的两支队伍和五桶燃料。
- **必须做的狂乱检定**：三处必须检定：① 第一次闻到旧站台里的血——饥渴狂乱，难度 3；② 第一次把人打到流血——愤怒狂乱，难度 2；③ 燃料被打翻之后——饥渴狂乱，难度 3 + 每多待一回合。

#### 四种收场

| 收场 | 代价 | 世界状态 |
| --- | --- | --- |
| **静默解决血仆，尸体和燃料都没有被发现** | 两支队伍仍会在站台上撞上，发生踩踏；特警随后封站，逮捕所有领头人。**宪兵暂时没有理由进场。** | 秩序 -2　正当性 -2　暴露度 +1 |
| **血仆死亡，尸体被队伍发现** | 队伍恐慌，踩踏升级为暴乱；宪兵开着吉普进入，直接开枪。**这一幕之后直接进入戒严。** | 秩序 -3　正当性 -3　暴露度 +2 |
| **血仆放火** | 火在旧站台里扩散；烟灌进通道，人群互相踩踏。宪兵以反恐名义入场，枪战不可避免。 | 秩序 -3　正当性 -3　暴露度 +4 |
| **夺走燃料，并把两支队伍错开** | 踩踏减轻，但特警仍然封站抓人。**玩家救下一些人，却救不了这场运动的政治命运。** | 秩序 -1　正当性 -1　资本信心 -1 |
| **什么都不做** | 血仆放火或留下尸体，队伍恐慌暴乱，宪兵入场枪战。**下一幕开始时，城市已经处于戒严状态。** | 秩序 -3　正当性 -3　暴露度 +3 |

**奖励**：玩家第一次面对一场不是为他们准备的埋伏，而他们的每一次干预都会改变下一批进场的人是谁。

**说书人注意**：**十三不在站台里。** 他在外面等无人机回传，然后决定要不要让宪兵看见更完整的现场。

### 人类立场（本阶段常量）

| 阵营 | 立场 | 烈度 | 合法 | 非法 | 超自然 | 本阶段行动效果 |
| --- | --- | --- | --- | --- | --- | --- |
| 主权派 | 激进 | 3 | 4 | 2 | 0 | 3 × 5 = **15** |
| 联盟派 | 激进 | 3 | 4 | 1 | 0 | 3 × 4.5 = **13.5** |
| 技术官僚派 | 管理 | 2 | 5 | 2 | 0 | 2 × 6 = **12** |

**立场按阶段固定，永远不变。变的是『这个立场此刻能做成多少事』——那由能力与世界状态决定。** 这就是人类能力矩阵的全部用途：
它不是『他们想不想』，而是『他们做得到多少』。

| 世界状态 | 对人类的杠杆 |
| --- | --- |
| 正当性 ≤ 3 | 主权派与联盟派 ×1.5（两边都更容易动员） |
| 秩序 ≤ 3 | 技术官僚派 ×0.5（国家自己都乱了，管不了） |
| 资本信心 ≤ 3 | 联盟派 ×1.5（『我们别无选择』变得可信） |
| 资本信心 ≥ 7 | 主权派 ×1.5（『我们撑得住』变得可信） |
| 暴露度 ≥ 7 | 全体人类 ×1.5（人人紧张，任何事都更容易引爆） |

### 血族态度锚点

本场结束时，无论世界状态是否越过阈值，以下变化都会触发：

| 派系 | 变化 | 原因 |
| --- | --- | --- |
| 缄默庭 | `patience -1` | 旧站台的抓捕被火和枪战打断 |
| 新血 | `patience -1` | 体制翼与窗外翼在同一条通道里互相看见 |
| 旧自由邦 | `patience -1` | 两条路线被同一场事故吞掉 |
| 街垒 | `patience -1` | 队伍遭到特警和宪兵双重打压 |

### 血族默认行动

| 派系 | 本幕行动 |
| --- | --- |
| 缄默庭 | 让特警在两支队伍相撞后封站，抓走所有领头人。 |
| 新血 | 体制翼向特警确认封站时间；窗外翼试图给其中一支队伍发警告。 |
| 旧自由邦 | 分别安排两支队伍走两条路，而他们没有检查两条路会在哪里汇合。 |
| 街垒 | 在其中一支队伍里，最先走进旧站台。 |
| 狂信团 | 十三派五名血仆下到旧站台，等两支队伍自己撞上来。 |

以上是**默认行动**。实际行动由局势引擎按各派系当前的立场、耐心与能力推导。
