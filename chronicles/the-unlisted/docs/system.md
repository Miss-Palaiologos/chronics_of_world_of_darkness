# 系统与派系

## 三分钟开局

玩家是夜里行动的年轻血族。现代政治正在把整座城市卷进一场主权危机，而他们同时被两个世界要求站队：

- 作为人类：你支持哪一种政治未来？
- 作为血族：你所属的派系允许你活到明天吗？

人类各方的立场按阶段固定，代表历史大势。血族的立场、耐心与能力可以在每一幕后改变。玩家能改变的只有血族一侧，以及事件中谁来承担代价。

## 人类：三个固定阵营

| 阵营 | 诉求 | 他们真正想要的 |
| --- | --- | --- |
| **主权派** | 全文公开、追责签字者、拆解联合机构 | 重新行使主权，不让秘密条约继续生效 |
| **联盟派** | 公开附件、让谈判继续 | 把已经运行的安排合法化，避免系统停摆 |
| **技术官僚派** | 管理危机、维持系统 | 不输掉危机，也不让城市停电 |

第三幕中，主权派与联盟派并没有改变诉求，只是口号不同：

- 主权派：**全文公开，追责签字者**
- 联盟派：**公开附件，谈判继续**

技术官僚派则派出妥协派代表到广场，说《区域稳定托管行政记录》仍在库存中翻找。实际上，缺的正是其中血族那一整块文件。

## 血族：五个派系

| 派系 | 立场 | 在剧情中的功能 |
| --- | --- | --- |
| **缄默庭（秘盟·老）** | 拖字 | 控制档案、政府关系与归因方向；把问题拖到别人先死 |
| **新血（秘盟·新）** | 拖字 | 体制内执行；第三幕促成政府妥协，让讲台成为刺杀现场 |
| **旧自由邦（叛党·老）** | 守土 | 出钱、出车、出路线；第四幕两条游行路线的组织者 |
| **街垒（叛党·新）** | 守土 | 进入学生与人类运动；玩家“人类身份”的镜子 |
| **狂信团（魔宴·新）** | 搅局 | 提供无人机、燃料和血仆，负责把局部冲突升级为失控 |

## 血族内斗：祸水东引

暴露度是全城的，归因不是。血族之间真正的斗争方式，是**把第二审判庭引到对手身上**：

- 借人类的手转交证据；
- 在现场留下对手的物件；
- 让现场看起来像某个组织而不是某个人做的；
- 让对手出现在不该出现的地方；
- 匿名举报对手的庇护所、血仆或猎场。

玩家能改的是证据和归因，不能降低已经产生的暴露度。暴露度达到 7 后，归因游戏失效；达到 10 后，第二审判庭直接清城。

## 一个场景的结算循环

1. 读当前人类立场（按阶段固定）。
2. 读世界状态：秩序、正当性、猎食条件、暴露度、资本信心。
3. 用血族当前立场、耐心、能力推导行动。
4. 玩家在场景中行动，给出来源、代价和结果质量。
5. 结算世界状态：固有脉冲 + 血族行动 + 玩家修正。
6. 检查三条崩盘轨道：戒严、审判庭、资本崩溃。
7. 更新血族态度，进入下一场。

## 固有脉冲与态度锚点

固有脉冲代表这一幕人类世界必然发生的变化。它不包含玩家行动，也不包含血族的随机发挥。

| 场景 | 秩序 | 正当性 | 猎食条件 | 暴露度 | 资本信心 | 解释 |
| --- | ---: | ---: | ---: | ---: | ---: | --- |
| E1 静水 | 0 | −1 | 0 | +1 | 0 | 秘密开始留下痕迹 |
| E2 告别 | 0 | −2 | +1 | +1 | 0 | 死亡成为公共事件，人群成为猎场 |
| E3 听证 | 0 | −2 | 0 | 0 | −1 | 托管档案进入公开记录 |
| E3T 讲台 | −3 | −3 | −1 | +1 | −2 | 刺杀、宵禁与控制场面同时发生 |
| E4 计中计 | −3 | −3 | 0 | +1 | −2 | 两支队伍相撞，特警与宪兵双双介入 |
| E6 档案之夜 | −1 | 0 | 0 | +1 | 0 | 血族在墓前相遇，避世风险上升 |
| E7 投票之夜 | +1 | −1 | 0 | 0 | +1 | 结果确定，秩序与资本暂时回升 |
| E8 拆除 | 0 | 0 | 0 | 0 | 0 | 尾声，不再改变世界状态 |

每一场还有**态度锚点**：无论世界状态是否越过阈值，特定派系都会按剧情强制改变耐心、能力或立场。锚点写在 `data/kindred.json` 的 `act_anchors` 中。规则是：

1. 锚点先触发，世界状态敏感度后触发。
2. 每场每项变化最多 ±1。
3. 耐心降到 2 或以下时，派系会为了止损消耗自己的资产，**能力再 −1**。

因此第三幕结束时，缄默庭与新血会被明确推入焦虑状态：前者失去部分资产与关系，后者被问责。

## 六幕结构

| 幕 | 事件 | 核心问题 |
| --- | --- | --- |
| **1 · 静水** | 极乐境与酒会同夜 | 这座城市平时由谁在管？ |
| **2 · 火种与两百页** | 告别 → 听证 | 一份死亡如何变成管辖权和档案问题？ |
| **3 · 讲台** | 和平游行、政府澄清、无人机刺杀 | 谁把妥协者送上了讲台？ |
| **4 · 计中计** | 两支游行汇入旧站台 | 特警抓人，还是宪兵开枪？ |
| **5 · 档案之夜** | 墓前争夺档案 | 谁有能力保存档案，谁只是想要它？ |
| **6 · 结算与拆除** | 投票 → 拆除 | 谁被交出去，什么被留下？ |

## 第一、二幕的归属支点

这两幕的目标不是发动大事件，而是让玩家先形成具体归属。

- **E1 · 秘盟法庭**：Gateway 拆迁带来领地与猎场纠纷，裁决引用《区域稳定托管行政记录》。长老只当它是程序，玩家却第一次听到这个名字。
- **E1 · 子嗣名单**：旧自由邦交给玩家一张名单，要求确认一批“按秘盟法律不该出生”的子嗣。名单尾页注明来源：区域稳定托管行政记录。
- **E2 · 林秀兰的请求**：如果玩家认识她，她会拜托玩家不要让孙子成为运动的旗帜。
- **E2 · 城市英雄**：搬椅子、分水、挡记者、保护警员、阻止视频传播——这些小事不会改变历史，但会建立本地关系。
- **E2 · 血族最初不关心**：除街垒和少数想利用守夜的人，血族对这个案子没有兴趣。是玩家自己把档案带进了血族政治。

## 崩盘与结束

| 轨道 | 触发 | 结果 |
| --- | --- | --- |
| **戒严** | 秩序 ≤ 2 且烈度 ≥ 12，或秩序 ≤ 1 | 本幕结束即游戏结束 |
| **审判庭** | 暴露度 ≥ 10 | 本幕结束即游戏结束 |
| **资本崩溃** | 资本信心 ≤ 1 | 本幕结束即游戏结束 |

只有**逃亡准备 ≥ 2** 的角色能在崩盘后离开。

## 自定义玩家行动

GUI 的「手动修正／自定义行动」页支持三种模式：

- 预设模板：`careful`、`normal`、`sloppy`、`reckless`；
- 自定义玩家行动：手动填写结果质量、目击超自然、制造混乱、逃亡准备增量和世界状态修正池；
- 主持人修正：在结算后直接调整世界状态、逃亡准备或任一血族派系的耐心、能力与立场。

命令行等价写法：

```powershell
python -m the_unlisted.cli advance --scene E3T `
  --quality 3 `
  --alloc legitimacy=2,exposure=2 `
  --witnessed 1 `
  --agitation 1 `
  --escape 1
```

`--quality` 每点提供 2 点世界状态修正池；`--alloc` 是结果修正，`--witnessed` 与 `--agitation` 是额外风险。

## 主持原则

- 人类立场是常量，不要临时改动。
- 血族立场是变量，玩家可以改变它。
- 每个场景只结算一次，不要在场与场之间重复结算。
- 不要让玩家靠“聪明解法”跳过代价；改变的是代价落在谁身上。
- 如果一个设定不改变玩家选择、不改变世界状态、也不提供线索，就删掉它。
